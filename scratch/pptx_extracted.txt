=== SLIDE 4 ===
INTRODUCTION
RISC-V
 is an open and modular Instruction Set Architecture (ISA) that supports application-specific instruction extensions. 
The flexibility of RISC-V enables the integration of 
custom instructions and dedicated hardware accelerators
 to improve processor performance. 
Multiply-Accumulate (MAC)
 is a fundamental operation in DSP and compute-intensive applications such as 
FIR filtering, dot-product computation and matrix operations
. 
Conventional execution of MAC operations requires multiple instructions, resulting in increased 
instruction count, execution cycles and processing time
. 
A 
custom MAC instruction
 can combine multiplication and accumulation into a single application-specific operation, reducing computational overhead. 
This project proposes the design and FPGA implementation of a 
performance-optimized RISC-V processor with a custom MAC instruction
. 
The proposed processor will be implemented and evaluated on the 
Xilinx PYNQ-Z2 FPGA
 using 
Vivado
. 
Core Concept:
RISC-V Processor → Custom MAC Instruction → Hardware MAC Unit → PYNQ-Z2 → Performance Evaluation

=== SLIDE 6 ===
PROBLEM STATEMENT
30/09/2026
6
To design and implement a custom MAC instruction in a RISC-V processor to reduce the execution overhead of MAC-intensive workloads and evaluate its performance, timing, FPGA resource utilization and power consumption on the PYNQ-Z2 platform.
MAC operations
 are frequently used in computationally intensive applications such as 
FIR filtering, dot-product and matrix operations
. 
In a conventional RISC-V processor, a MAC operation requires multiple arithmetic instructions, increasing the 
instruction count and execution cycles
. 
Repeated execution of these operations can lead to increased 
execution time and computational overhead
. 
Although RISC-V supports custom instruction extensions, designing an application-specific instruction requires careful consideration of the 
processor 
datapath
, FPGA resources and performance benefits
. 
Therefore, there is a need for a 
lightweight custom MAC instruction
 that can accelerate MAC-intensive workloads while maintaining reasonable FPGA resource utilization. 
Existing accelerator-based approaches are often designed for specific applications and may introduce additional 
hardware resource and power overhead
.
